КУСКОВАТОСТЬ ПОРОДЫ ПО ФОТО
===========================

Программа определяет гранулометрический состав (кусковатость) взорванной
породы по фотографии: выделяет отдельные куски, строит график и таблицу
содержания кусков по классам крупности.

Установка не нужна, Python и другие программы ставить не надо.
Нужен компьютер с Windows 10 или 11 (64-бит).


ЗАПУСК
------
1. Распакуйте архив целиком: правая кнопка мыши -> «Извлечь все...».
   Из самого архива, без распаковки, программа не запустится.
   Папку можно положить куда угодно: на диск D:, на рабочий стол, на флешку.
2. Откройте распакованную папку и дважды щёлкните «Kuskovatost» (Kuskovatost.exe,
   значок Python).
3. При самом первом запуске программа около минуты готовит библиотеки (видно
   окошко «подготовка библиотек… %») — это делается один раз на компьютере.
4. Программа предложит создать ярлык на рабочем столе — дальше её можно
   запускать ярлыком «Кусковатость породы по фото».

Kuskovatost.exe — это официальный Python (подписан Python Software Foundation)
под другим именем, остальное — библиотеки из открытых пакетов. Поэтому
Smart App Control в Windows 11 программу не блокирует, права администратора не
нужны. Библиотеки распаковываются в папку
%LOCALAPPDATA%\KuskovatostFoto (около 400 МБ); её можно удалить, если
программа больше не нужна.


РАБОТА
------
* «Открыть фото...» или перетащите фото (или папку с фото) в окно программы.
  Можно также перетащить фото на Kuskovatost.exe.
* Если на фото виден поднятый ковш экскаватора с породой, программа сама
  находит его и сразу считает породу в ковше.
* Если ковша нет, программа просит обвести мышью область для расчёта:
  щелчки левой кнопкой — вершины контура, двойной щелчок или правая кнопка —
  замкнуть контур. Можно просто обвести область, ведя мышь с нажатой кнопкой.
  Кнопка «Обвести контур» работает на любом фото.
* Масштаб (сколько миллиметров в одном пикселе) нужен, чтобы получить размеры
  в мм. Если ковш найден — масштаб берётся по ширине ковша (поле «Ширина
  ковша»). Иначе нажмите «Эталон» и проведите линию по предмету известной
  длины, затем введите его длину в мм.
* На фото цветными контурами показаны найденные куски. Голубая штриховка —
  мелочь: участки между кусками, где отдельные куски мельче предела
  разрешения (около 30-40 мм на снимках с камеры экскаватора). Мелочь входит в
  гранулометрический состав как мелкая фракция (строка «в т.ч. мелочь» в
  таблице); галочка «учитывать мелочь» позволяет посмотреть состав только по
  выделенным кускам. Серая штриховка — участки, которые не удалось распознать
  (в расчёт не входят).
* Колесо мыши — увеличить фото, перетаскивание — сдвинуть, двойной щелчок —
  вписать фото в окно.
* «Убрать фото» (или клавиша Delete в списке) — убрать фото из списка и из
  средних значений.
* «Сохранить отчёт...» — таблица results.csv (открывается в Excel), график
  и фото с выделенными кусками.

Примеры фото — в папке «Примеры фото».


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
Программа записывает журнал в папку logs рядом с Kuskovatost.exe (или, если
туда нельзя писать, в %LOCALAPPDATA%\KuskovatostFoto\logs). Пришлите файл
foto.log разработчику.
