# Кусковатость породы по фото — демонстрационная версия

Упрощённый вариант программы: вместо видео на вход подаются **фотографии**.
Сегментация кусков и расчёт гранулометрии — те же, что в основной программе
(`fragmentation/segment.py`, `metrics.py`).

Для каждого фото:

1. Программа сама ищет **поднятый ковш с породой** (по шаблонам корпуса блока,
   как в основной программе). Если ковш найден, область анализа — порода между
   стенками ковша, масштаб мм/пикс — по ширине ковша на каждой строке
   (перспектива учитывается).
2. Если ковш **не найден** (ковш внизу у забоя, вне кадра, пустой, или на фото
   его вообще нет), программа предлагает **обвести мышью контур** области, где
   считать кусковатость. Обвести контур можно и на любом фото, где ковш найден, —
   кнопка «Обвести контур».
3. После расчёта показываются:
   * **найденные куски** — цветные контуры прямо на фото (колесо мыши —
     увеличение, перетаскивание — сдвиг, двойной щелчок — вписать в окно);
   * **график**: гранулометрический состав этого фото (остальные фото — серым)
     и X50/X80 по всем фото со средними;
   * **таблица** содержания кусков по классам крупности, % по массе — для этого
     фото и среднее по всем фото;
   * X50, X80, средневзвешенный и максимальный размер куска.

## Запуск на Windows

1. Нужен Python 3.10–3.13 (подходит ваш 3.13). `install.bat` сам найдёт
   подходящую версию.
2. Дважды щёлкнуть **`install.bat`** — создаёт окружение `.venv`, ставит
   библиотеки (первый раз 5–10 минут, нужен интернет) и кладёт на рабочий стол
   ярлык **Kuskovatost foto**.
3. Запуск — ярлыком или **`start.bat`**. Фото можно перетащить на `start.bat`
   или прямо в окно программы (можно и целую папку).

Ошибки при запуске через ярлык пишутся в `logs/foto.log`.

## Работа в окне

| кнопка | что делает |
|---|---|
| **Открыть фото…** | выбрать одно или несколько фото (jpg, png, bmp, tif, webp) |
| **Найти ковш** | заново искать ковш и посчитать породу в нём |
| **Обвести контур** | обвести область мышью: щелчки — вершины, двойной щелчок / правая кнопка / Enter — замкнуть; можно просто обвести, ведя мышь с нажатой кнопкой. Backspace — шаг назад, Esc — отмена |
| **Эталон** | провести линию по предмету известной длины и ввести её длину в мм — задаёт масштаб мм/пикс для обведённой области |
| **Ширина ковша** | реальная ширина ковша по наружным стенкам, мм (эталон размера при автопоиске) |
| **Масштаб** | мм/пикс для обведённой области; ставится сам по ковшу или эталону, можно ввести вручную |
| **Расчёт: Точно / Быстро** | «Быстро» считает по уменьшенному фото — в 2–4 раза быстрее, мелкие куски теряются |
| **Распознать** | пересчитать текущее фото (после смены масштаба, ширины ковша и т. п.) |
| **Сохранить отчёт…** | папка `kuskovatost_foto_<дата>`: `results.csv` (таблица по всем фото, открывается в Excel), `granulometry.png`, `overlays/` — фото с найденными кусками |

Слева — список фото; щелчок по фото показывает его результат. В таблице и на
нижнем графике «среднее» — по всем посчитанным фото.

### Масштаб для обведённой области

Размеры в мм зависят от масштаба, поэтому для обведённой области он берётся так:

* ковш найден на этом фото (даже внизу) — по его ширине; это приближение,
  точное для области на той же глубине, что и ковш;
* иначе — по **эталону** (лучше всего) или введённое вручную число мм/пикс;
* если ничего не задано, масштаб условный — программа предупредит жёлтой
  строкой.

## Примеры

В папке `primery/` — кадры из тестового видео:

* `1_…`, `2_…`, `3_…` — поднятый ковш с породой: ковш находится автоматически,
  расчёт идёт сразу;
* `4_забой_ковш_внизу.jpg`, `5_забой_без_ковша.jpg` — ковш у забоя или его нет
  в кадре: программа просит обвести контур (масштаб — через «Эталон»).

## Ограничения

* Автопоиск ковша настроен на эту камеру и этот экскаватор (шаблоны в
  `fragmentation/assets/`). На фото с другой машины ковш, скорее всего, не
  найдётся — тогда работает обведённый контур.
* Сегментация настроена на кадры примерно 1920 px по ширине; более крупные фото
  уменьшаются до этой ширины. Большая обведённая область (больше ~650 тыс.
  пикселей) считается на уменьшенной копии, поэтому расчёт занимает до ~15–20 с.
* Куски мельче предела разрешения (≈ 6 пикселей) не различимы и учитываются как
  «неразрешённая площадь» — она показывается в строке под фото.
